The following are key characteristics of a local search:
1. Iterative improvement -local search repeatedly refines the current solution.
2. Neighbourhood exploration -It focuses on exploring solutions that are similar to the current one.
3. Heuristic - It doesn’t guarantee to find the absolute best solution (global optimum), but it aims to find a good solution (local optimum) in a reasonable amount of time.
4. Problem-specific The definition of ”neighbourhood” and the evaluation function are specific to the problem being solved.
