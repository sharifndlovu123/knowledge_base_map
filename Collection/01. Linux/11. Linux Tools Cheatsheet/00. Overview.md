## Where things go

- Anything about editing text in the terminal (keys, modes, config, plugins) goes under `Text Editors`.
- Terminals, multiplexers and anything about running many shells at once goes under `Terminals and Multiplexers`.
- A new tool gets its own folder if it needs several notes, or a single note in this folder if it fits on one page.
- Broad command lists stay in [[Basic Commands]] and [[Toolset]].
